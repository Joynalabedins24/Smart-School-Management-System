A modern **ERP-based School Management System** built with **Laravel**, designed to automate and manage the complete academic and administrative workflow of educational institutions.

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/Joynalabedins24/Smart-School-Management-System.git
```

### Go to Project

```bash
cd Smart-School-Management-System
```

### Install Dependencies

```bash
composer install
```

```bash
npm install
```

### Create Environment File

```bash
cp .env.example .env
```

### Generate Application Key

```bash
php artisan key:generate
```

### Configure Database

Update your `.env` file

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=root
DB_PASSWORD=
```

### Run Migration & Seeder

```bash
php artisan migrate --seed
```

### Start Development Server

```bash
php artisan serve
```

### Run Vite

```bash
npm run dev
```

Open your browser:

```
http://127.0.0.1:8000
```
