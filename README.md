# Smart School Management System

## Features
- Attendance system (class & section wise)
- Monthly report with percentage
- Calendar view with status
- PDF export & print system

## Tech Stack
Laravel, MySQL, JavaScript, Bootstrap

## Installation
1. Clone repo
2. composer install
3. copy .env
4. php artisan migrate
5. php artisan serve
